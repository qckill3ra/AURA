# AURA

## Autonomous Unified Reasoning Assistant

AURA est une intelligence artificielle personnelle locale conçue pour assister son utilisateur dans :

- Programmation
- Cybersécurité
- Administration système
- Automatisation
- Gestion d'un homelab
- Analyse technique

---

# Philosophie

AURA suit quatre principes :

## Local First

Les données restent locales.

## Security First

Aucune action critique sans validation.

## Modular Architecture

Chaque composant peut évoluer indépendamment.

## Human Control

AURA assiste. Elle ne décide jamais seule.

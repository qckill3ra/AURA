# Contributing

Merci de contribuer à AURA.


## Règles

Chaque modification doit :

- être documentée
- avoir des tests
- respecter l'architecture
- respecter la sécurité


## Branches

main

develop

feature/


## Commits

Format :

type: description


Exemple :

feat: add memory service

fix: repair llm provider


## Documentation

Toute nouvelle fonctionnalité doit ajouter :

- Documentation
- Diagramme si nécessaire
- Changelog
